# Segurança e privacidade

Os downloads oficiais estão em https://github.com/Zkyzer/devflow-care/releases.

A beta não tem assinatura digital. Compare os arquivos com `SHA256SUMS.txt` para verificar integridade. Não desative as proteções do Windows para executar o aplicativo.

Não publique tokens, arquivos pessoais, relatórios completos, caminhos locais ou nomes de usuários em issues. Use o diagnóstico resumido em **Sobre o Care → Exportar diagnóstico** e revise antes de compartilhar.

Para um problema de segurança que exponha dados, evite divulgar detalhes sensíveis em uma issue pública. Abra uma issue pedindo um canal privado ao mantenedor, sem incluir o conteúdo sensível.
